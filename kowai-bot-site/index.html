Sistema Completo de Coleta e Tradução de Histórias Japonesas

Projeto em Node.js criado para estudar automação, web scraping e tradução de textos. Coleta histórias diretamente do site e as traduz do japonês para português brasileiro.

Coletor de Histórias

Baixa histórias diretamente do site usando apenas o ID da URL. Menu interativo para selecionar quais histórias baixar. Extrai automaticamente título e conteúdo e salva em arquivos .txt organizados.

Tradutor Automático

Traduz histórias do japonês para português brasileiro. Divisão inteligente de textos longos (supera limites da API). Menu interativo para escolher traduções individuais ou em lote. Verifica automaticamente quais histórias já foram traduzidas.

Estrutura Organizada

Pasta separada para histórias em japonês e traduzidas. Scripts modulares para diferentes funcionalidades. Código limpo e bem documentado para fácil manutenção e expansão.

AVISO IMPORTANTE

O bot NÃO roda no navegador

Este site é apenas uma página demonstrativa. O scraping e a coleta das histórias são feitos localmente usando Node.js.

Execução Local

Para rodar o bot, é necessário instalar Node.js e executar os scripts via terminal.

Funcionalidades Principais

Interface Interativa

Menus CLI amigáveis para selecionar histórias e opções de tradução

Web Scraping

Extrai conteúdo de forma eficiente e responsável do site fonte

Tradução Automática

Integração com API do Google Translate para traduções rápidas

Processamento em Lote

Traduza uma história específica ou todas as não traduzidas de uma vez

Como Usar

1

Primeiro Passo: Baixar Histórias

Execute o coletor de histórias para baixar as histórias do site.

node baixador-interativo.js

No menu interativo, escolha entre histórias pré-definidas ou digite os IDs manualmente.

2

Segundo Passo: Traduzir Histórias

Execute o tradutor para converter as histórias para português.

node traduzir-menu.js

No menu do tradutor, veja todas as histórias disponíveis e escolha quais traduzir.

3

Configuração Rápida

Para baixar histórias específicas, edite o arquivo baixar-rapido.js:

const IDs = [14905, 8883, 7675]; // Adicione mais IDs aqui!

Para personalizar a lista de histórias populares, edite baixador-interativo.js.
